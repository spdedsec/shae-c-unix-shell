# SHAE — Deutsche Dokumentation

## Installation
Führe `scripts/install.sh` aus, um die C-Unix-Shell zu installieren.

## Plattform
CLI-Tool (C-Sprache).

## Build
`gcc -O2 -std=c11 -o shae-shell src/shell.c -lreadline`

## Release
GitHub Release v0.1.0 verfügbar.

## Design
Folgt dem SHAE Field Manual: warm paper #F2EEE5, ink #191712, oxide #B3341B, 0px Radius, 1px Rahmen.
